# FitSpeak 데모

영어 프리토킹 앱 **FitSpeak**의 발표용 1단계 데모입니다.

## 특장점

이 앱은 단순 문법 교정보다, 사용자가 각 상황에서 말하고자 하는 바를 명확하게 말할 수 있도록 피드백하는 것을 목표로 합니다.

- 프리토킹: 친구, 직장동료, 고객 등 누구와 대화해도 자연스럽고 유창하게 말하기
- 회의: Business English로 설득력과 next step을 분명하게 만들기
- 발표: 구조화와 전달력을 높여 청중이 따라오기 쉽게 말하기
- 면접: 논리, STAR 구조, 자신감을 살려 답변하기
- 여행: 생존형 표현과 즉답성으로 바로 통하게 말하기

## 현재 구현 범위

- 상황 선택: 회의, 발표, 면접, 여행
- 첫 화면 세션: 오늘 연습, 복습 세션, Mock Practice
- 아이폰 화면 기준의 모바일 우선 UI
- 브라우저 음성 인식 연결
- 말하기 화면, 마이크 버튼, 인식 문장 표시
- 음성 인식 결과를 기준으로 데모 피드백 생성
- 문법 수정, 자연스러운 문장, 표현 설명, 대체 표현 카드
- 복습 세션에서 내가 자주 쓰는 어색한 표현을 다시 말할 수 있게 정리
- 말하기 중 비슷한 실수 패턴을 카테고리별 리마인드로 표시
- Mock Practice에서 Job Interview, Presentation, Meeting, Networking, Conference Q&A 선택
- Mock Practice 시간 설정, 메인 질문 답변, 답변 후 꼬리 질문/예상 밖 질문/구체화 요청/재질문 흐름

## 실행

```bash
npm.cmd install
npm.cmd run web -- --port 8081
```

브라우저에서 아래 주소를 열면 됩니다.

```text
http://localhost:8081
```

## AI 피드백 연결

API 키는 프론트 코드에 넣지 않고 로컬 API 서버에서만 사용합니다.

1. `.env.example`을 참고해서 `.env.local` 파일을 만듭니다.
2. `.env.local`에 `OPENAI_API_KEY`를 넣습니다.
3. 별도 터미널에서 API 서버를 실행합니다.

```bash
npm.cmd run api
```

웹 앱은 `http://localhost:8787/api/feedback`으로 피드백을 요청합니다. `OPENAI_API_KEY`가 없거나 API 요청이 실패하면 앱은 자동으로 데모 피드백을 보여줍니다.

## 음성 인식 사용

웹 데모는 Chrome 또는 Edge의 음성 인식 기능을 사용합니다.

1. 상황을 선택하고 연습을 시작합니다.
2. 마이크 버튼을 누릅니다.
3. 브라우저가 마이크 권한을 요청하면 허용합니다.
4. 영어로 말하면 "음성 인식 결과"에 문장이 표시됩니다.
5. "피드백 보기"를 누르면 인식된 문장이 피드백 화면에 반영됩니다.

인앱 브라우저나 일부 브라우저에서는 마이크 권한이 제한될 수 있습니다. 이 경우 Chrome 또는 Edge에서 `http://localhost:8081`을 열어 테스트하면 됩니다.

현재 피드백은 API 연결 전 단계의 데모 로직입니다. `explain about`, `discuss about`, `how can I go`, `I want to` 같은 대표 패턴은 문장에 맞춰 교정하고, 그 외 문장은 선택한 상황에 맞춰 자연스러운 구조 예시를 보여줍니다.

## 복습과 Mock Practice

복습 세션은 내가 했던 표현, 더 자연스러운 표현, 기억할 포인트, 상황별 짧은 예문을 카드로 보여줍니다. 말하기 중 같은 패턴이 다시 나오면 해당 카테고리의 리마인드 박스를 표시합니다.

Mock Practice는 아래 상황을 지원합니다.

- Job Interview
- Presentation
- Meeting
- Networking
- Conference Q&A

사용자는 3분, 5분, 10분, 15분 중 시간을 고를 수 있습니다. Mock Practice가 시작되면 먼저 상황별 메인 질문이 나오고, 사용자가 답변한 뒤 후속질문 받기 버튼으로 꼬리 질문, 예상 밖 질문, 구체화 요청, 재질문을 이어서 받을 수 있습니다.
